# YouTube MP3 Downloader

A NiceGUI web app that extracts MP3 audio from YouTube videos.

## Setup

Requires: ffmpeg, Node.js 22+

```bash
./setup.sh
```

## Run

```bash
python app.py
```

Open http://localhost:8080 and enter a YouTube URL.
